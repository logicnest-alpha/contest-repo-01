## Caption (Instagram Reels / YouTube Shorts description)

Most cold emails die in spam before anyone reads them. Here's the setup I'm learning, step by step:

1️⃣ Separate sending domain. Never your main one
2️⃣ SPF + DKIM + DMARC on that domain
3️⃣ Warm up each inbox for ~2 weeks
4️⃣ Max ~30 emails/day per inbox
5️⃣ Verify every address (keep bounces under 2%)

The email:
→ Under 80 words, plain text, no links
→ Line 1 = something true about THEM
→ One problem
→ A small question, not a meeting ask

The script I'm testing:
"Hi {name}, saw you're {specific thing}.
Usually that means {problem}.
I'm building {one-line solution} for exactly that. Worth a look?"

Then 3 follow-ups (day 4, 8, 14). Each adds something new. Never "just bumping this."
